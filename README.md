## ✨ Features & Architecture

- **3D / WebGL Canvas**: Interactive rendered 3D character powered by **Three.js** & **React Three Fiber**
- **Smooth Animations**: GSAP timeline transitions, text splitters, & Lenis smooth scroll
- **Modular Config Architecture**: Clean data-driven configuration in `src/config.ts`
- **Structured Portfolio Showcase**: Clear visual distinction between **Professional Work** and **Open Source Projects**

## 🧰 Tech Stack

- **Automation & Engineering**: Revit API, Excel VSTO, .NET, MEP Calculator, Process Automation
